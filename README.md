# Faculty Development, by Design

A connected faculty-development system for online and hybrid teaching, built as a spec project for a faculty development and instructional design role at Pearl River Community College.

**Live site:** https://wjdenius.github.io/faculty-development-portfolio/

## The idea

Most faculty-development efforts fail in the same place: a workshop teaches an idea, everyone nods, and nothing changes in the actual course. This project treats that as a design problem rather than a motivation problem. Three artifacts work as one loop — course review finds the gap, coaching closes it, and a workshop scales the fix across the faculty.

## What's inside

The whole project is one self-contained page with four tabs:

- **Overview** — the premise and how the pieces fit together.
- **Coaching Framework** — a nine-stage, non-evaluative coaching cycle, with faculty personas, intake and observation instruments, and an evaluation plan.
- **Course Quality Rubric** — an original ten-category rubric for online and hybrid courses, with four performance levels, an accessibility gateway, a scoring guide, and a worked sample review.
- **Workshop** — a 90-minute hands-on session with a facilitator guide, participant workbook, and job aids, plus a downloadable 22-slide deck embedded right in the page.

## Frameworks and methods

Human Performance Technology and Gilbert's Behavior Engineering Model, ADDIE, Design Thinking, Universal Design for Learning, the Kirkpatrick model, Thalheimer's LTEM, Dessinger and Moseley's full-scope evaluation, and applied behavior analysis. Accessibility (WCAG 2.1 AA) is built in throughout rather than retrofitted.

## How it's built

A single self-contained HTML file — no build step, no dependencies, no external assets. The styles are inlined, the slide deck is embedded and rebuilt as a real PowerPoint file on download, and the layout is responsive and keyboard-navigable. Drop the one file on any static host and it runs.
